# AURA — Fashion E-Commerce Website

AURA is a full-stack fashion e-commerce web application built to provide users with a simple and engaging online shopping experience.

## ✨ About the Project

AURA is a group project that combines frontend development, backend functionality, and database management to create a fashion-focused e-commerce platform.

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Database:** SQL
- **Frontend:** HTML, CSS, JavaScript
- **Version Control:** Git and GitHub

## 🚀 Features

- Fashion e-commerce interface
- Product browsing
- Database-driven functionality
- Backend integration using Flask

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/supriya-p22/AURA-Ecommerce.git
cd AURA-Ecommerce
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it:

**Windows**
```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file using `.env.example` as a reference.

Add your own database credentials and Flask secret key.

### 5. Set up the database

Configure your SQL database, then run the database setup script if required:

```bash
python setup_db.py
```

### 6. Run the application

```bash
python app.py
```

Open the local URL displayed in your terminal.
